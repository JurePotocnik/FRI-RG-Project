# FRI-RG-Project

This project is now a small interactive Three.js sandbox focused on floating voxel islands.

## What's new

- Procedurally generated island clusters with three world presets
- Animated floating islands with selection highlights
- HUD with live world stats and selected-island details
- Camera focus, keyboard panning, and mouse-based zoom/orbit controls
- Responsive landing layout instead of a blank canvas

## Controls

- Drag with the mouse to orbit
- Right-drag to pan
- Mouse wheel to zoom
- `W`, `A`, `S`, `D` or arrow keys to pan the camera
- `R` to regenerate the current world preset
- `Space` to pause or resume animation
- `F` to focus the camera on the selected island
- `1`, `2`, `3` to switch world presets
